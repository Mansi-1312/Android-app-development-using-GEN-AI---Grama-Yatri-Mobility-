Project Overview

Grama-Yatri is an Android application designed to provide real-time rural bus tracking and live ETA updates using community participation. The app helps passengers know the expected arrival time of buses by allowing users to send live “Ping” updates whenever they see or board a bus.

The application uses Firebase Realtime Database for instant synchronization and GenAI-based logic for smarter ETA prediction. Grama-Yatri aims to reduce waiting time, improve rural connectivity, and make public transportation more reliable for students, workers, and daily commuters.

⚙️ How It Works
User opens the app and selects a route
Users send a “Ping” when they see or board the bus
Data is stored in Firebase Realtime Database
The system calculates ETA using route data and average travel time
Live ETA updates are shown to all users instantly
Notifications are sent for delays or cancellations
